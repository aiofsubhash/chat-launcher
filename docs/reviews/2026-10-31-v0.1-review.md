# Review - v0.1.0 (Oct 31, 2026)

Scope: first build (chat home screen, app suggestions, message drafts, focus profiles, LLM chat, HTML bubbles).

## Fixed in this pass
- App list was re-queried from PackageManager on every keystroke; now loaded once into `appListCache` and filtered in memory.
- Settings profile editor was limited to the 6-item suggestion cap; now lists all launchable apps (`limit = Int.MAX_VALUE`).
- Kotlin compile error in suggestion ranking (`indexOf(query, true)` -> `indexOf(query, ignoreCase = true)`).

## Safety boundaries checked
- No auto-send: all message actions open a share-sheet draft; the user confirms in the target app.
- API key lives only in app-private SharedPreferences; never in the repo. Improvement candidate: EncryptedSharedPreferences.
- HTML responses render in a WebView with JavaScript disabled and navigation blocked; remote images can still load (accepted for v1, note for v2: proxy or strip remote content).
- LLM receives chat history (including drafts typed in chat) once the user adds their own key - expected; do not log it elsewhere.

## Notes
- `shouldOverrideUrlLoading(view, url)` override is deprecated; fine on minSdk 26+ for now.
- Emulator runtime verification is environment-blocked (no /dev/kvm in the build sandbox); device smoke test pending on a real phone.
