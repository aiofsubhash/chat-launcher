# Compound pass (run synchronously, one pass at a time)

Adapted from ce-compound (https://github.com/EveryInc/compound-engineering-plugin).

After each completed loop, write `docs/solutions/<date>-<topic>.md`: what was built, what broke and how it was found, decisions taken and why, and what the next loop should reuse. Keep it short - a future pass reads this before touching the same code.
