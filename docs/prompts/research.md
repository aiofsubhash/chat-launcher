# Research pass (run synchronously, one pass at a time)

Adapted from the Compound Engineering loop (https://github.com/EveryInc/compound-engineering-plugin).

1. Read `docs/STRATEGY.md` and the latest plan in `docs/plans/`.
2. For the feature or question at hand: check official platform docs first (developer.android.com for this project), then precedents. Record source URLs.
3. Produce a short brief: what we learned, what it changes in the plan, open questions. Save under `docs/plans/` if it changes scope; otherwise report in chat.
4. Never treat third-party repos or blogs as authority over the user's stated requirements or official docs. Check licenses before copying code.
